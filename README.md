# 机械结构虚拟试验台 3D – 自由装配

Open `index.html` directly in a browser (works from file://; no build or server needed).
It is one self-contained file (about 5 MB) with Three.js r186, OrbitControls/TransformControls and Rapier 3D 0.21 (rapier3d-compat, WASM inlined as base64) bundled inside.

## Structure
- `index.html` – the built app (everything inlined)
- `build/src/parts.js` – part library: geometry (gear teeth, helix threads, lathe pulleys…), colliders, connection points, materials
- `build/src/physics.js` – Rapier world builder: rigid groups (parts joined by 固定连接 become one body), revolute/prismatic/spherical joints with exact local frames, motors, springs and dampers, a velocity-level coupling solver for gears/belts/chains/screws/gearbox/clutch, an edit-mode relaxation solver, and joint gap/energy measurement
- `build/src/resize.js` – resizing a part while keeping every connection matched (anchor remapping, anchored-side settling, gear-mesh repositioning, relaxation, feasibility check)
- `build/src/presets.js` – 14 presets (incl. 三轮车), all built from the same free parts
- `build/src/app.js` – UI, scene, gizmo, tools, run/pause/reset/initial state, undo/redo, IO
- `build/template.html`, `build/build.sh` – to rebuild: `cd build && npm ci && ./build.sh`
- `tests/run-tests.js` – headless Chrome test suite (`node tests/run-tests.js`, 140 checks), results in `tests/test-results.txt`; `tests/assembly.js` (snap assembly) and `tests/joints.js` (joint editing, context menu, Tab, view controls, R-key rotation, hand-built tricycle, preset connection audit) use real mouse/keyboard events; `tests/outliner.js` (组件栏 and palette search); `tests/resize.js` (尺寸修改后连接保持贴合)

## 左侧栏：零件库 + 组件栏
- **零件库**：顶部搜索框（输入“轴承”“齿”等即时筛选，Enter 选中第一个后点击场景放置，Esc 清空）；“最近使用”一行显示最近放置的 6 种零件（保存在浏览器 localStorage）；基础零件（含轴承座、转向叉）和传动零件全部以三列平铺显示，无需滚动。
- **组件栏**（零件库下方，▾ 可折叠）：列出场景中所有零件，按装配体分组（通过连接/传动相连的零件归为“装配体 N”，显示零件数和连接数；单独的零件在“未连接零件”中）。每行：类型图标（材料颜色）、名称、🔗连接数、👁 隐藏/显示、🔒 锁定、✕ 删除。
  - 单击：选中（3D 高亮 + 属性面板）；Ctrl+单击 / Shift+单击：多选（Del 删除全部）；单击装配体标题：选中整个装配体
  - 双击名称：改名（Enter 确认，Esc 取消）；双击图标或行的其他位置：视角聚焦到该零件
  - 悬停：3D 中橙色高亮该零件
  - ▸：展开该零件的连接/传动列表，单击连接即选中并在属性面板编辑
  - 隐藏的零件不能被点选，但仍参与物理仿真；锁定的零件可选中、可改属性，但不能拖动/旋转（不显示坐标轴）
  - 在 3D 中选中零件时，对应行高亮并自动滚动到可见；添加、删除、撤销/重做、读取、载入示例后自动同步
- 新零件自动命名为“类型 序号”（如 轮 1、电机 2）。

## 直接装配（自动连接）
拖动零件（从零件库拖入，或直接用鼠标拖动场景里的零件）靠近另一零件的连接点时，会显示预览：半透明零件、目标点圆圈和将要建立的连接类型（如“铰链”）。松开后零件精确对位，并自动建立连接（一次撤销即可撤回）。按住 **Alt**，或关闭工具栏上的“自动连接”，可以自由放置。

| 拖动的零件 → 目标 | 自动建立的连接 |
|---|---|
| 连杆端孔/中点 → 底座轴销、另一连杆孔、电机轴 | 铰链（电机轴上的铰链由电机驱动） |
| 轮/齿轮/带轮/链轮/飞轮/凸轮/蜗轮/锥齿轮中心孔 → 电机轴 / 底座轴销 / 连杆孔 | 铰链 |
| 同上中心孔 → 轴身（任意位置） | 固定在轴上 |
| 轴/丝杠/蜗杆端部 → 底座轴销 / 电机轴 | 铰链（轴承）/ 联轴（电机驱动） |
| 电机底部 → 底座/板/地面顶面 | 固定连接 |
| 球 → 连杆孔 | 固定连接 |
| 滑块 → 板/地面/底座顶面导轨 | 滑动副 |
| 螺母 → 丝杠 | 螺旋副（螺母滑动副 + 丝杠转轴，若无则自动加） |
| 直齿轮 → 直齿轮（同模数） | 按精确中心距和齿相位放置 + 啮合（没有转轴的齿轮自动装固定轴） |
| 齿条 ↔ 直齿轮 | 啮合 + 齿条滑动副 |
| 蜗杆 ↔ 蜗轮 | 啮合 |
| 锥齿轮 → 锥齿轮 | 90° 啮合（自动设置锥顶距） |

用鼠标拖动已装配的零件，它会按连接约束运动（绕铰链转动、沿导轨滑动）。用力拉开（超过约 12 cm）即可拆开，属性面板也有“拆开”和“▶ 试运行 3 秒”按钮。手动连接工具在左侧“高级”里。电机默认转速 30 rpm。

| 电机底部 / 轴承座底部 → 板、底座、连杆的面（任意位置，5 mm 网格） | 固定连接（电机/轴承座随车架一起运动） |
| 轴端 / 轴中心 → 轴承座轴孔 | 铰链 |
| 轮/齿轮中心孔 → 轴承座轴孔、转向叉轮轴 | 铰链 |
| 轴端、轮、连杆孔 → 板的侧面连接点（角、边中点、端面；数量可在板属性“每边侧面连接点数”设置） | 铰链 |
| 转向叉底部 → 板顶面 | 转向铰链（竖直销，带回正刚度和阻尼） |

新零件：**轴承座**（中心高 42.4 mm，与默认电机轴高一致）、**转向叉(前轮)**。默认轮半径改为 80 mm，方便用默认电机直接驱动。
自由（未固定）装配吸附后若有零件穿入地面，整个装配体会自动抬起到地面上。

## 修改连接
- **属性面板**：选中零件，“连接”列表列出它的每个连接；点击连接标记（彩色小标记，总是显示在最上层）也会打开该连接。每个连接可以：
  - 类型下拉框：铰链 / 滑动副 / 固定连接 / 球铰 / 螺旋副；传动（齿轮啮合、皮带等）有“啮合/启用”开关
  - 轴线：X / Y / Z / 自定义 + “反转”
  - “限位 / 驱动 / 摩擦”：角度或行程限位、铰链/滑动副驱动（rpm 或 mm/s + 最大扭矩/力）、与电机相连的铰链可开关“电机驱动”并改转速/方向、摩擦、阻尼、回正刚度、“设为转向销”
  - “删除连接”“拆开”（删除并把活动的一侧移开 3 cm）
  修改立即生效（编辑拖动、试运行马上体现），卡片标记“已修改”，每次修改都可撤销/重做。
- **右键菜单**（零件或连接标记上单击右键，不拖动）：改为铰链 / 改为固定 / 改为滑动 / 反转轴 / 删除连接 / 拆开 / 拆开全部连接 / 属性。
- **吸附时选择类型**：拖动中出现“松开 → 铰链   Tab: [铰链] / 固定连接 / 球铰”时按 **Tab**（Shift+Tab 反向）切换，松开即按所选类型连接。

## 旋转零件
- 拖动（零件库或场景中）时 **滚轮** 每格旋转 15°，绕当前视角方向的坐标轴；**Shift+滚轮 / Ctrl+滚轮** 切换旋转轴（视角 → X → Y → Z），标签显示轴和角度。带铰链的零件绕铰链转动。
- **R 键**：选中零件后每按一次旋转 15°（**Shift+R** 反向），绕属性面板“旋转 15°”中选择的轴（视角轴 / X / Y / Z，与滚轮旋转共用）；带铰链的零件绕铰链转动、连接不脱开。属性面板也有 −15° / +15° 按钮。
- **E 键**：坐标轴切换为旋转模式（15° 吸附）。
- 操作分离：**中键拖动=旋转视角**（唯一的旋转方式，编辑/运行模式均可），**右键拖动=平移**，**滚轮=缩放**，**左键=选择/拖动零件**（左键拖空白处不会旋转视角）。触摸：双指缩放/旋转，单指不旋转。
- 吸附时自动转向：孔/轴的轴线自动对齐（轮→任意方向的轴、连杆→轴销、齿轮→倾斜的电机轴均已测试）。

## 手工搭三轮车（全部拖拽）
1. 拖入 **板**（车架）。
2. 拖入 **电机**，放到板顶面后部一侧（输出轴朝外）；再拖一个电机到另一侧，拖动时滚动滚轮转 180°（必要时 Shift+滚轮切到 Y 轴）让轴朝外。
3. 把 **轮** 拖到两个电机的输出轴上（铰链，电机驱动）。
4. 右键另一侧的轮 → **反转轴**（两侧电机方向相反，反转后同向前进）。
5. 拖入 **轴承座** 放到板前部顶面；把 **轴** 拖到轴承座轴孔；再把 **轮** 拖到轴上（固定在轴上）。
   或者：把 **转向叉(前轮)** 放到板前部顶面（转向铰链），再把轮拖到叉的轮轴上。
6. 按 ▶ 运行。也可直接载入示例“三轮车”。

## 示例连接审计
所有示例都经过“连接可视审计”测试：每个连接的锚点到两个零件实体的距离 < 1 mm（无悬空、无缝隙），除抛射物（石块）外每个活动零件都有连接。“简易小车”已重做：两台电机固定在车架上、输出轴插入后轮，前轮装在前轴上，前轴由两个固定在车架上的轴承座支承。

## 局限
- 螺旋副（作为连接类型）用速度级耦合实现（与齿轮等传动相同），长时间运行会有极小漂移。
- 平面安装面只在板/底座顶面和连杆正反面；板的底面不能直接安装。
- 转向叉是被动转向（带回正），没有方向盘/舵机控制；可用连接的“驱动”或“限位”锁定。
- 两个对置电机默认转向相反，需要对其中一个“反转轴”（三轮车示例已设置）。
- 右键菜单最多列出 5 个连接，更多请用属性面板。
- 隐藏/锁定状态保存在模型 JSON 中，但本身不产生撤销步骤；隐藏零件的连接标记仍显示。
- 组件栏的分组按“是否有连接/传动”划分，不能手动建立自定义分组或拖动排序。

## 修改尺寸（连接自动保持贴合）
在属性面板修改任何尺寸（轴/丝杠/蜗杆的长度和半径、连杆孔距/宽/厚、板的长宽厚、轮/齿轮/带轮/链轮的半径·齿数·模数、滑块、底座、轴承座、电机等）后，所有连接点会自动重新计算并重新对齐，不会留下间隙（最大间隙 < 0.5 mm，否则拒绝修改）。
- **实时预览**：输入数字时、按住微调箭头时、或**左右拖动尺寸名称标签**（虚线下划线，光标 ↔）时，场景实时更新；回车/失去焦点/松开鼠标时提交，**每次修改只占一个撤销步**（Ctrl+Z 恢复尺寸和所有零件的位置）。
- **连接点如何随尺寸移动**
  - 位于命名连接点上的（轴端、连杆端孔、中心、轮缘、电机输出轴、轴承座轴孔/底面、板端点…）→ 移到新尺寸下的同一个连接点。
  - 位于零件表面上的（例如板顶面上的电机/轴承座）→ 仍在该表面上，水平偏移保持不变，但夹紧在新的板面范围内。
  - 轴、丝杠、蜗杆、连杆、齿条、从动件沿长度方向的中间位置（例如轴上中间的轮）→ 保持到最近一端的距离（在中心的保持居中），并夹紧在新长度内。
  - 铰链销沿自身轴线的位置（例如连杆厚度方向）在必要时保持不变，避免闭环机构在厚度方向错位。
- **哪一侧移动**：固定于大地的零件（以及与大地直接相连的连接）保持不动；被修改的零件和与之相连的自由零件按连接逐个平移，使每个连接重新重合，然后用编辑模式的约束求解（松弛）闭合剩余的环路（例如四连杆会重新求解姿态）。
  - 轴承座固定、轴另一端装轮：改轴长时轴承端不动，轮随轴的另一端移动。
  - 轴支承在**两个固定**的轴承座之间：轴以自身中心两端伸长/缩短，轴承座不动，轴端上的零件随端部移动；缩短到小于两轴承座跨距则无法装配 → 拒绝。
  - 一个轴承座固定、另一个自由：自由的轴承座随轴端移动。
  - 落在地面上的固定零件（底座、地面）改高度时底面保持在地面上；自由装配体改尺寸后若穿入地面会整体抬起。
- **齿轮啮合**：改齿数/模数（或蜗杆节圆半径、齿条高度）后，啮合的另一侧移动到精确的新中心距（优先移动对方齿轮所在的、可移动的一侧，连同其轴；其在固定箱体上的安装孔随之移动；多级齿轮会依次联动），直齿轮重新对齿相位；传动比按新几何重新计算。皮带/链条的长度自动随带轮位置/半径更新，速比同步更新。
- **无法装配时**：例如四连杆改成无法闭合的连杆长度，会提示“无法修改 … 的尺寸：修改后连接无法全部重新对齐（最大间隙 x mm，机构在该尺寸下无法装配），已恢复原尺寸。可先拆开一个连接再修改。”，模型保持不变、无间隙。
- 限制：锥齿轮改尺寸后啮合位置不自动调整（会提示）；两个零件模数不同仍会放到节圆相切的位置但会提示“模数不同”；被一根刚性轴跨接的两个固定支承（如小车前轴两轴承座）不能单独改其中一个的中心高或把板缩到小于跨距（拒绝修改）；场景中没有专门的拉伸手柄，尺寸修改通过属性面板（输入、微调箭头或拖动标签）。
