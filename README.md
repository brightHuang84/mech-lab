# 机械结构虚拟试验台 3D – 自由装配

Open `index.html` directly in a browser (works from file://; no build or server needed).
It is one self-contained file (about 5 MB) with Three.js r186, OrbitControls/TransformControls and Rapier 3D 0.21 (rapier3d-compat, WASM inlined as base64) bundled inside.

## Structure
- `index.html` – the built app (everything inlined)
- `build/src/parts.js` – part library: geometry (gear teeth, helix threads, lathe pulleys…), colliders, connection points, materials
- `build/src/physics.js` – Rapier world builder: rigid groups (parts joined by 固定连接 become one body), revolute/prismatic/spherical joints with exact local frames, motors, springs and dampers, a velocity-level coupling solver for gears/belts/chains/screws/gearbox/clutch, an edit-mode relaxation solver, and joint gap/energy measurement
- `build/src/resize.js` – resizing a part while keeping every connection matched (anchor remapping, anchored-side settling, gear-mesh repositioning, relaxation, feasibility check)
- `build/src/presets.js` – 15 presets (incl. 三轮车 and 四轮小车(通用零件装配)), all built from the same free parts
- `build/src/importer.js` – STL (binary/ASCII) / OBJ / GLB / GLTF (embedded) import: parsing, welding, decimation, volume, convex hull
- `build/src/asmpanel.js` – 装配面板：连接点列表（中文名）、智能默认配对、对位计算、实时预览、确定/交换/取消、链式/全部到第一个、已有连接编辑
- `build/src/extra.js` – 坐标轴开关、导入、我的零件、自定义连接点、配合工具、组合/复制/镜像、运行时按键
- `build/src/examples.js` – 四轮小车示例：只用通用零件、通过与用户相同的 API（mate / 组合 / 镜像 / 关节驱动）搭建
- `build/src/app.js` – UI, scene, gizmo, tools, run/pause/reset/initial state, undo/redo, IO
- `build/template.html`, `build/build.sh` – to rebuild: `cd build && npm ci && ./build.sh`
- `tests/run-tests.js` – headless Chrome test suite (`node tests/run-tests.js`, 238 checks; wheel ground cases in `tests/ground-wheel.js`, shaft-length resize in `tests/resize-joints.js`), results in `tests/test-results.txt`; `tests/assembly.js` (snap assembly) and `tests/joints.js` (joint editing, context menu, Tab, view controls, R-key rotation, hand-built tricycle, preset connection audit) use real mouse/keyboard events; `tests/outliner.js` (组件栏 and palette search); `tests/resize.js` (尺寸修改后连接保持贴合); `tests/features.js` (坐标轴开关、STL/OBJ/GLB 导入与存读、沿杆任意位置吸附、面贴合、配合、关节限位/弹簧编辑、组合镜像、四轮车行驶验证); `tests/asmpanel.js`（各种选中途径都不出现坐标轴、装配面板默认配对/对位/撤销/链式/预览取消，并生成两张截图）；测试模型在 `tests/fixtures/`

## 左侧栏：零件库 + 组件栏
- **零件库**：顶部搜索框（输入“轴承”“齿”等即时筛选，Enter 选中第一个后点击场景放置，Esc 清空）；“最近使用”一行显示最近放置的 6 种零件（保存在浏览器 localStorage）；基础零件（含轴承座、转向叉）和传动零件全部以三列平铺显示，无需滚动。
- **组件栏**（零件库下方，▾ 可折叠）：列出场景中所有零件，按装配体分组（通过连接/传动相连的零件归为“装配体 N”，显示零件数和连接数；单独的零件在“未连接零件”中）。每行：类型图标（材料颜色）、名称、🔗连接数、👁 隐藏/显示、🔒 锁定、✕ 删除。
  - 单击：选中（3D 高亮 + 属性面板）；Ctrl+单击 / Shift+单击：多选（Del 删除全部）；单击装配体标题：选中整个装配体
  - 双击名称：改名（Enter 确认，Esc 取消）；双击图标或行的其他位置：视角聚焦到该零件
  - 悬停：3D 中橙色高亮该零件
  - ▸：展开该零件的连接/传动列表，单击连接即选中并在属性面板编辑
  - 隐藏的零件不能被点选，但仍参与物理仿真；锁定的零件可选中、可改属性，但不能拖动/旋转（不显示坐标轴）
  - 在 3D 中选中零件时，对应行高亮并自动滚动到可见；添加、删除、撤销/重做、读取、载入示例后自动同步
- 新零件自动命名为“类型 序号”（如 轮 1、电机 2）。

## 装配面板（推荐的装配方式）
不需要在 3D 里拖动对位：
1. 单击第一个零件（A，**固定不动的基准**），再 **Ctrl+单击 / Shift+单击** 第二个零件（B，**要移动的零件**）。画布和左侧组件栏都可以这样多选。
2. 右侧自动出现 **🔧 装配** 面板（也可以按 **J** 或点工具栏“🔧 装配”打开）。面板已经按零件类型选好默认连接：
   - 齿轮 + 轴 → 固定在轴身上；轮/带轮 + 轴 → 固定
   - 连杆端孔 + 连杆端孔 → 铰链（两杆自动错开一层，不重叠）
   - 两个同模数齿轮 → 齿轮啮合（中心距自动计算）
   - 轴 + 轴承座 → 铰链（轴穿过轴孔）
   - 带轮 + 带轮 → 皮带；链轮 + 链轮 → 链条；丝杠 + 螺母 → 螺旋；滑块 + 板 → 滑动；电机 + 齿轮/轮 → 装在输出轴上（铰链，由电机驱动）
3. 需要时修改：
   - **连接类型**：固定 / 铰链(转动) / 滑动 / 球铰 / 齿轮啮合（只对能啮合的零件出现）/ 皮带 / 链条 / 螺旋
   - **A、B 的连接点**：列表里是中文名（如“端孔A（孔）”“轴身（沿轴身·位置可调）”“顶面”，导入零件的自定义连接点也会列出）。轴身、杆身这类连接点可以输入沿轴的位置（mm）。鼠标悬停在列表项上，3D 里会显示该点的标记（A 橙色、B 蓝色、悬停黄色）；也可以直接在 3D 模型上**单击 A 或 B 的位置**来选连接点。
   - **轴线**（自动 / X / Y / Z）、**反向**、**偏移**（mm）、**旋转角度**（°）
4. 修改时实时预览：B 半透明显示在装配后的位置。**⇄ 交换 A/B** 可以改为移动另一个零件。
5. 点 **✓ 确定装配**（Enter）：B 连同与它相连的整个组件一起移到 A 上并建立连接，一次 Ctrl+Z 即可撤销。点 **取消**（Esc）恢复原样。

选中 3 个及以上零件时可以选 **链式**（A–B、B–C、C–D…）或 **全部连到第一个**，每一对都能单独修改。选中零件之间已有的连接会列在面板里，可以直接改类型或删除。

## 选中与坐标轴
单击零件（画布、组件栏）、从零件库拖入、载入示例、撤销、吸附、配合、组合或装配后，零件**只高亮，不显示坐标轴**。需要精确平移或旋转时按 **G / Shift+G**（或工具栏“坐标轴”）；改变选择后坐标轴自动隐藏。旧版本保存在浏览器里的坐标轴设置会在启动时清除。左键拖动零件仍然可以直接移动它。

## 直接装配（拖动自动连接，可选）
拖动零件（从零件库拖入，或直接用鼠标拖动场景里的零件）靠近另一零件的连接点时，会显示预览：半透明零件、目标点圆圈和将要建立的连接类型（如“铰链”）。松开后零件精确对位，并自动建立连接（一次撤销即可撤回）。按住 **Alt**，或关闭工具栏上的“自动连接”，可以自由放置（拖动场景里的零件时 Alt = 只移动这个零件并拆开它）。

| 拖动的零件 → 目标 | 自动建立的连接 |
|---|---|
| 连杆端孔/中点 → 底座轴销、另一连杆孔、电机轴 | 铰链（电机轴上的铰链由电机驱动） |
| 轮/齿轮/带轮/链轮/飞轮/凸轮/蜗轮/锥齿轮中心孔 → 电机轴 / 底座轴销 / 连杆孔 | 铰链 |
| 同上中心孔 → 轴身（任意位置） | 固定在轴上 |
| 轴/丝杠/蜗杆端部 → 底座轴销 / 电机轴 | 铰链（轴承）/ 联轴（电机驱动） |
| 电机底部 → 底座/板/地面顶面 | 固定连接 |
| 球 → 连杆孔 | 固定连接 |
| 滑块 → 板/地面/底座顶面导轨 | 滑动副 |
| 螺母 → 丝杠 | 螺旋副（螺母滑动副 + 丝杠转轴，若无则自动加） |
| 直齿轮 → 直齿轮（同模数） | 按精确中心距和齿相位放置 + 啮合（没有转轴的齿轮自动装固定轴） |
| 齿条 ↔ 直齿轮 | 啮合 + 齿条滑动副 |
| 蜗杆 ↔ 蜗轮 | 啮合 |
| 锥齿轮 → 锥齿轮 | 90° 啮合（自动设置锥顶距） |

左键拖动已装配的零件会把整个装配体一起移动；按住 **Ctrl** 拖动则按连接约束运动（绕铰链转动、沿导轨滑动），用力拉开（超过约 12 cm）即可拆开；**Alt** 拖动只移动这个零件。属性面板也有“拆开”和“▶ 试运行 3 秒”按钮。手动连接工具在左侧“高级”里。电机默认转速 30 rpm。

| 电机底部 / 轴承座底部 → 板、底座、连杆的面（任意位置，5 mm 网格） | 固定连接（电机/轴承座随车架一起运动） |
| 轴端 / 轴中心 → 轴承座轴孔 | 铰链 |
| 轮/齿轮中心孔 → 轴承座轴孔、转向叉轮轴 | 铰链 |
| 轴端、轮、连杆孔 → 板的侧面连接点（角、边中点、端面；数量可在板属性“每边侧面连接点数”设置） | 铰链 |
| 转向叉底部 → 板顶面 | 转向铰链（竖直销，带回正刚度和阻尼） |

新零件：**轴承座**（中心高 42.4 mm，与默认电机轴高一致）、**转向叉(前轮)**。默认轮半径改为 80 mm，方便用默认电机直接驱动。
自由（未固定）装配吸附后若有零件穿入地面，整个装配体会自动抬起到地面上。

## 坐标轴（Gizmo）
选中零件时**不显示**坐标轴，可直接拖动或用 R 旋转。多选 / 组件栏点“装配体”标题选中整组时，G 坐标轴放在选中中心，拖动/旋转全部一起动；右侧多选面板有“中心位置 X/Y/Z”和“旋转”输入框。需要精确平移/旋转时按 **G**（移动）或 **Shift+G**（旋转），再按一次隐藏，选别的零件后自动隐藏；工具栏“坐标轴”按钮、右键菜单“显示移动坐标轴 / 显示旋转坐标轴”效果相同。

## 导入 3D 零件（STL / OBJ / GLB / GLTF）
- 工具栏 **📥 导入零件**，或直接把文件**拖进 3D 视图**。支持 STL（二进制和 ASCII）、OBJ、GLB、内嵌资源的 GLTF。
- 导入对话框：单位（mm / cm / m / inch，STL/OBJ 默认 mm，GLB/GLTF 默认 m，显示换算后的尺寸）、材料（质量 = 体积 × 密度，体积由网格计算，网格不封闭时用凸包体积）、碰撞体（**凸包**：可动；**精确网格(三角网格)**：只能固定于大地，适合底座/场地）、“加入我的零件”。
- 模型自动居中（包围盒中心），过大的网格自动简化（≤ 40000 三角形），凸包 ≤ 200 点。
- 自动连接点：包围盒 6 个面中心（面贴合）+ 中心；任意面都可作为“面”参与吸附。
- **自定义连接点**：选中导入零件 → 属性面板“＋ 在表面添加连接点”（或工具栏“＋连接点”），点击模型表面，选择类型（孔 / 轴 / 安装面），连接点沿表面法线方向；属性面板列出并可删除。
- 几何数据随保存文件（JSON）一起保存，读取、设为初始状态、撤销/重做都保留；组件栏显示 ◆ 图标。
- **组件库：我的零件**：勾选“加入我的零件”后出现在零件库“我的零件”一栏（保存在浏览器 localStorage），可像普通零件一样拖入，✕ 移除。

## 通用装配工具
- **沿杆 / 板任意位置吸附**：轮、齿轮、连杆孔、轴销等可以吸到连杆杆身任意位置（5 mm 网格）；板的**全部 6 个面**、滑块/底座/导入零件的各个面都可作为安装面（面贴合，默认固定，可 Tab 切换为铰链/滑动/球铰）。离散连接点优先于“任意位置”。
- **配合（M）**：两次点击——第一次点要移动的零件的面（或连接点），第二次点目标零件的面。移动零件使两面贴合（法线相对），然后在顶部工具条调整：类型（固定/铰链/滑动/球铰）、轴线（法向/X/Y/Z）、偏移（mm，沿法向）、绕法向角度、“同向”，点“确定”提交（一次撤销）。导入零件同样适用。
- **关节编辑器**（属性面板连接卡片 → “限位 / 驱动(电机) / 弹簧阻尼 / 按键”）：
  - 类型、轴线（X/Y/Z/自定义、反转）、角度或行程限位
  - 任意关节的 **弹簧刚度 + 平衡位置 + 阻尼**（例如滑动副做悬架）
  - **内置电机**（铰链/滑动副）：模式“速度”（rpm 或 mm/s，最大扭矩/力）、“扭矩”、“位置/舵机”（目标角度或位置）
  - **按键绑定**：点“正向键”/“反向键”框再按一个键（如 W 和 S、A 和 D）。运行时：速度模式按键时以 ±目标速度驱动、松开滑行；舵机模式按住转到 ±目标角，松开回中。状态栏显示“键盘控制：A / D / W / S”。
- **组合 / 复制 / 镜像**：Ctrl/Shift+单击 多选（或单击装配体标题），属性面板出现多选面板：组合、取消组合、复制（含内部连接，Ctrl+D 亦可）、镜像（选择镜像平面 X/Y/Z 和位置；可选“含外部连接”，镜像后会自动与原来连接的零件建立对应连接）。镜像后铰链轴方向按镜像规则反向、限位对调；导入零件生成镜像几何。

## 用通用零件搭一辆四轮车（示例“四轮小车(通用零件装配)”就是这样搭出来的）
1. 拖入 **板** 作为车架（如 500×20×240 mm，铝）。
2. 拖入 **滑块**，按 **M** 配合：先点滑块侧面，再点车架侧面靠前的位置 → 类型选“滑动”、轴线 Y（竖直）→ 确定。关节编辑器里设 **弹簧刚度**（如 1500 N/m）、阻尼 60、行程限位 ±25 mm → 悬架。
3. 再拖一个滑块（转向节），配合到悬架滑块外侧面，类型“铰链”、轴线 Y；关节编辑器设限位 ±30°、驱动“位置/舵机”目标 22°，绑定 **A / D**。
4. 拖入 **轮**（r 60 mm），配合到转向节外侧面，类型“铰链”、轴线“法向”。
5. 后部同样：滑块（悬架）+ 轮；在后轮铰链的驱动里选“速度”，设转速和最大扭矩，绑定 **W / S**（方向不对就“反转”轴或交换按键）。
6. Ctrl+单击选中一侧的悬架块、转向节、两个轮 → Ctrl+G 组合 → 多选面板“镜像”，平面 Z、位置 0，勾选“含外部连接” → 另一侧自动生成并连到车架（按键绑定一起复制；镜像侧的转向如方向相反，在关节编辑器点“反转”）。
7. ▶ 运行：W 前进，S 后退，A/D 转向。示例中 2 秒约行驶 1.4 m，带 A 转向约 45°，越过“减速带”时车身保持水平，无 NaN。

## 修改连接
- **属性面板**：选中零件，“连接”列表列出它的每个连接；点击连接标记（彩色小标记，总是显示在最上层）也会打开该连接。每个连接可以：
  - 类型下拉框：铰链 / 滑动副 / 固定连接 / 球铰 / 螺旋副；传动（齿轮啮合、皮带等）有“啮合/启用”开关
  - 轴线：X / Y / Z / 自定义 + “反转”
  - “限位 / 驱动 / 摩擦”：角度或行程限位、铰链/滑动副驱动（rpm 或 mm/s + 最大扭矩/力）、与电机相连的铰链可开关“电机驱动”并改转速/方向、摩擦、阻尼、回正刚度、“设为转向销”
  - “删除连接”“拆开”（删除并把活动的一侧移开 3 cm）
  修改立即生效（编辑拖动、试运行马上体现），卡片标记“已修改”，每次修改都可撤销/重做。
- **右键菜单**（零件或连接标记上单击右键，不拖动）：改为铰链 / 改为固定 / 改为滑动 / 反转轴 / 删除连接 / 拆开 / 拆开全部连接 / 属性。
- **吸附时选择类型**：拖动中出现“松开 → 铰链   Tab: [铰链] / 固定连接 / 球铰”时按 **Tab**（Shift+Tab 反向）切换，松开即按所选类型连接。

## 旋转零件
- 拖动（零件库或场景中）时 **滚轮** 每格旋转 15°，绕当前视角方向的坐标轴；**Shift+滚轮 / Ctrl+滚轮** 切换旋转轴（视角 → X → Y → Z），标签显示轴和角度。带铰链的零件绕铰链转动。
- **R 键**：选中零件后每按一次旋转 15°（**Shift+R** 反向），绕属性面板“旋转 15°”中选择的轴（视角轴 / X / Y / Z，与滚轮旋转共用）；带铰链的零件绕铰链转动、连接不脱开。属性面板也有 −15° / +15° 按钮。
- **E 键**：坐标轴切换为旋转模式（15° 吸附）。
- 操作分离：**中键拖动=旋转视角**（唯一的旋转方式，编辑/运行模式均可），**右键拖动=平移**，**滚轮=缩放**，**左键=选择/拖动零件**（左键拖空白处不会旋转视角）。触摸：双指缩放/旋转，单指不旋转。
- 吸附时自动转向：孔/轴的轴线自动对齐（轮→任意方向的轴、连杆→轴销、齿轮→倾斜的电机轴均已测试）。

## 手工搭三轮车（全部拖拽）
1. 拖入 **板**（车架）。
2. 拖入 **电机**，放到板顶面后部一侧（输出轴朝外）；再拖一个电机到另一侧，拖动时滚动滚轮转 180°（必要时 Shift+滚轮切到 Y 轴）让轴朝外。
3. 把 **轮** 拖到两个电机的输出轴上（铰链，电机驱动）。
4. 右键另一侧的轮 → **反转轴**（两侧电机方向相反，反转后同向前进）。
5. 拖入 **轴承座** 放到板前部顶面；把 **轴** 拖到轴承座轴孔；再把 **轮** 拖到轴上（固定在轴上）。
   或者：把 **转向叉(前轮)** 放到板前部顶面（转向铰链），再把轮拖到叉的轮轴上。
6. 按 ▶ 运行。也可直接载入示例“三轮车”。

## 示例连接审计
所有示例都经过“连接可视审计”测试：每个连接的锚点到两个零件实体的距离 < 1 mm（无悬空、无缝隙），除抛射物（石块）外每个活动零件都有连接。“简易小车”已重做：两台电机固定在车架上、输出轴插入后轮，前轮装在前轴上，前轴由两个固定在车架上的轴承座支承。

## 局限
- 螺旋副（作为连接类型）用速度级耦合实现（与齿轮等传动相同），长时间运行会有极小漂移。
- 转向叉是被动转向（带回正）；需要键控转向请用关节编辑器的“位置/舵机”驱动 + 按键绑定。
- 导入：不识别圆柱孔/轴（只有包围盒面和手动添加的连接点）；GLTF 外部 .bin / 贴图不支持（请用 GLB 或内嵌 GLTF），不导入材质颜色；精确网格碰撞体只能固定于大地；导入零件的尺寸只能整体缩放。
- 同一关节上启用驱动时，驱动代替该关节的弹簧（舵机本身就是弹簧+阻尼）。
- 没有差速器耦合；两个后轮各自由按键驱动（速度模式下相当于两台电机）。
- 装配面板：齿轮啮合只认同模数、轴线平行（或锥齿轮/蜗杆等已支持的组合）；皮带/链条把 B 放到与 A 同一平面，按当前方位角和自动中心距摆放；非“丝杠+螺母”的螺旋连接使用固定导程 5 mm；被移动的一侧如果固定于大地或两边都固定于大地，面板只建立连接不移动零件。
- 装配面板打开时开始拖动零件、运行、撤销、载入示例等操作会先取消面板中的预览。
- 配合偏移不为 0 时，连接锚点位于两零件之间的空隙中（连接审计会显示间隙）。
- 镜像的舵机/电机方向按几何镜像，按键语义可能需要在镜像侧“反转”一次。
- 组合只是选择分组（一起选中/移动/复制/镜像），不是刚性连接；需要刚性请用固定连接。
- 两个对置电机默认转向相反，需要对其中一个“反转轴”（三轮车示例已设置）。
- 右键菜单最多列出 5 个连接，更多请用属性面板。
- 隐藏/锁定状态保存在模型 JSON 中，但本身不产生撤销步骤；隐藏零件的连接标记仍显示。
- 组件栏的分组按“是否有连接/传动”划分（Ctrl+G 组合只影响选择），不能拖动排序。

## 修改尺寸（连接自动保持贴合）
在属性面板修改任何尺寸（轴/丝杠/蜗杆的长度和半径、连杆孔距/宽/厚、板的长宽厚、轮/齿轮/带轮/链轮的半径·齿数·模数、滑块、底座、轴承座、电机等）后，所有连接点会自动重新计算并重新对齐，不会留下间隙（最大间隙 < 0.5 mm，否则拒绝修改）。
- **实时预览**：输入数字时、按住微调箭头时、或**左右拖动尺寸名称标签**（虚线下划线，光标 ↔）时，场景实时更新；回车/失去焦点/松开鼠标时提交，**每次修改只占一个撤销步**（Ctrl+Z 恢复尺寸和所有零件的位置）。
- **连接点如何随尺寸移动**
  - 位于命名连接点上的（轴端、连杆端孔、中心、轮缘、电机输出轴、轴承座轴孔/底面、板端点…）→ 移到新尺寸下的同一个连接点。
  - 位于零件表面上的（例如板顶面上的电机/轴承座）→ 仍在该表面上，水平偏移保持不变，但夹紧在新的板面范围内。
  - 轴、丝杠、蜗杆、连杆、齿条、从动件沿长度方向的中间位置（例如轴上中间的轮）→ 保持到最近一端的距离（在中心的保持居中），并夹紧在新长度内。
  - 铰链销沿自身轴线的位置（例如连杆厚度方向）在必要时保持不变，避免闭环机构在厚度方向错位。
- **被约束的一侧不动（优先策略）**：每个连接在建立时（装配面板 / 🧲 配合 / 拖动吸附 / 连接工具）都记录参数化连接点（连接点名 + 沿轴位置 / 轴向偏移，`j.ref`）。改尺寸时，先看被改零件上的每个连接点连到哪里：连到大地/固定零件、连到电机/板/底座/轴承座等结构、连到有齿轮/皮带啮合的零件，或同一装配体从两处以上连到它 → 该连接点**保持世界位置不动**；若它在一端（例如电机输出端），这一端不动，零件只在另一端伸缩。其余（如轴端的轮）→ 端部的跟随端部、沿轴身的保持到最近一端的距离、其它保持到不动一侧的距离。两端都被约束无法同时保持、或啮合会脱开 → 拒绝并恢复原尺寸（中文提示）。
- **哪一侧移动**：固定于大地的零件（以及与大地直接相连的连接）保持不动；被修改的零件和与之相连的自由零件按连接逐个平移，使每个连接重新重合，然后用编辑模式的约束求解（松弛）闭合剩余的环路（例如四连杆会重新求解姿态）。
  - 轴承座固定、轴另一端装轮：改轴长时轴承端不动，轮随轴的另一端移动。
  - 轴支承在**两个固定**的轴承座之间：轴以自身中心两端伸长/缩短，轴承座不动，轴端上的零件随端部移动；缩短到小于两轴承座跨距则无法装配 → 拒绝。
  - 一个轴承座固定、另一个自由：自由的轴承座随轴端移动。
  - 落在地面上的固定零件（底座、地面）改高度时底面保持在地面上；自由装配体改尺寸后若穿入地面会整体抬起。
- **齿轮啮合**：改齿数/模数（或蜗杆节圆半径、齿条高度）后，啮合的另一侧移动到精确的新中心距（优先移动对方齿轮所在的、可移动的一侧，连同其轴；其在固定箱体上的安装孔随之移动；多级齿轮会依次联动），直齿轮重新对齿相位；传动比按新几何重新计算。皮带/链条的长度自动随带轮位置/半径更新，速比同步更新。
- **无法装配时**：例如四连杆改成无法闭合的连杆长度，会提示“无法修改 … 的尺寸：修改后连接无法全部重新对齐（最大间隙 x mm，机构在该尺寸下无法装配），已恢复原尺寸。可先拆开一个连接再修改。”，模型保持不变、无间隙。
- 限制：锥齿轮改尺寸后啮合位置不自动调整（会提示）；两个零件模数不同仍会放到节圆相切的位置但会提示“模数不同”；被一根刚性轴跨接的两个固定支承（如小车前轴两轴承座）不能单独改其中一个的中心高或把板缩到小于跨距（拒绝修改）；场景中没有专门的拉伸手柄，尺寸修改通过属性面板（输入、微调箭头或拖动标签）。

### 装配面板：选连接点（2026-10 改进）
- 面板打开时只显示 A（橙）/B（蓝）两个零件的大号连接点（● 点、■ 面、线 = 轴身/杆身），其它连接标记隐藏；正在选点的零件旁显示中文点名。
- 鼠标悬停：显示点名、位置和结果（→ 固定 / 铰链 …），绿色半透明预览装配结果；点击即选（可穿过 B 的半透明预览点到 A）。Tab 或面板 ①A/②B 切换选点零件。
- 点轴“前端/后端/中心”给轮/齿轮：自动齐平装在轴端 / 轴中点。轴身、杆身、板面、轮/齿轮正背面（偏心）可点任意位置，并可在 3D 中拖动；面板有滑块、mm、% 输入和 后端/中点/前端 快捷键。
- ⭐ 推荐连接：按兼容性和距离排序，点击一行即应用（行内也有轴端/中点快捷按钮）。
- 手动：连接类型随时可选（手动选择后再改点不会被覆盖）；两杆夹角（平行/45°/90°/自定义）、交叉连接、偏移 ±5、旋转 ±15/±90、反向。
