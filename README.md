# 机械结构虚拟试验台

基于浏览器的机构虚拟试验台：先仿真，再按结果做实物。当前为二维正置曲柄滑块。

## 功能

- 可调曲柄半径 r、连杆长度 l、转速、滑块质量、载荷与摩擦
- 实时动画，精确运动学与动力学
- 位置、速度、加速度、扭矩实时曲线
- 参数扫描，并高亮最优设计
- 导出设计 JSON、仿真 CSV、SVG 尺寸图与 BOM
- 导入实测位置 CSV，标定后与仿真对比，给出 RMS 误差

## 使用

用浏览器直接打开 `index.html`，无需构建。

公式测试：

```bash
node test-core.js
```

## 局限

忽略曲柄与连杆的质量、惯量；仅无偏距水平曲柄滑块；库仑摩擦；稳态单周期。
