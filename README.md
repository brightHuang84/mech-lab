# 机械结构虚拟试验台

三维自由装配机构虚拟试验台，模仿真实世界：在三维空间里装配零件，点「运行」，从任意角度观察运动。先仿真，再按结果做实物。

## 功能

- 轨道相机，视角预设：前视、俯视、侧视、轴测
- 零件：基座、杆、轴、轮、滑块、板、球、地面/墙、电机
- 传动：带齿直齿轮、齿条、锥齿轮、蜗杆与蜗轮、皮带轮/皮带、链轮/链条、凸轮/从动件、丝杠/螺母、飞轮、减速器、离合器、万向节
- 关节：转动副、移动副、固定、球铰、弹簧、阻尼器
- 移动/旋转手柄，带吸附
- 编辑模式无重力，拖动时保持已有连接
- 「设为初始状态」与重置
- 实时转速、速度、力、力矩、功率，轨迹、能量读数与曲线
- 13 个预设：单摆、曲柄滑块、四连杆、两级齿轮减速器、锥齿轮、蜗杆、皮带、链条、齿条、凸轮、丝杠、电动四轮小车、投石机
- JSON 保存/读取，导出 BOM（CSV）与 PNG
- 撤销/重做。快捷键：`Space` 运行/暂停，`Del` 删除，`Ctrl+Z` / `Ctrl+Y` 撤销/重做，`Ctrl+S` 保存，`W` / `E` 移动/旋转，`Esc` 取消，`F` 适应视图

## 使用

用浏览器打开 `index.html`。单文件，可离线使用，无需构建。

## 局限

- 齿轮、皮带、链条、丝杠按速比耦合，齿形仅作显示
- 万向节为 1:1
- 凸轮为偏心圆盘
- 仅在 Chrome 中测试过
