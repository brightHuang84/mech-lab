# 机械结构虚拟试验台

基于浏览器的自由装配机构虚拟试验台：从零件库拖出构件、连成机构，点「运行」看运动。先仿真，再按结果做实物。

## 功能

- 零件库：固定点、杆件、轮子、滑块、地面/墙、弹簧、阻尼器、电机、重物
- 连接：铰链、滑动副、固定焊接
- 二维刚体物理：重力、摩擦、碰撞
- 实时速度/力箭头、轨迹、能量读数与曲线
- 6 个预设：单摆、曲柄滑块、四连杆、弹簧-质量、投石机、斜面滚轮与滑块
- 保存/读取 JSON，导出 BOM（CSV）与 PNG
- 撤销 / 重做

## 使用

用浏览器直接打开 `index.html`，无需构建。

- `Space`：运行 / 暂停
- `Delete`：删除
- `R`：旋转
- `Ctrl+Z` / `Ctrl+Y`：撤销 / 重做

## 局限

- 仅二维
- 电机固定在地面
- 极端质量比钳制到 1:1000，以保证稳定
- 无连续碰撞检测，过快的细长物体可能穿透
- 仅在 Chrome 中测试过
