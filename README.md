# 机械结构虚拟试验台

基于浏览器的自由装配机构虚拟试验台：从零件库拖出构件、连成机构，点「运行」看运动。先仿真，再按结果做实物。

## 功能

- 零件库：固定点、杆件、轮子、滑块、地面/墙、弹簧、阻尼器、电机、重物
- 传动零件（19 种）：齿轮、内齿圈、齿条、锥齿轮、蜗杆与蜗轮、皮带轮+皮带、链轮+链条、凸轮+从动件、棘轮棘爪、槽轮机构（拨盘+槽轮）、联轴器/离合器、飞轮、减速器、丝杠+螺母、万向节
- 连接：铰链、滑动副、固定焊接、啮合/接触、皮带、链条
- 二维刚体物理：重力、摩擦、碰撞
- 编辑模式无重力、不自由仿真；拖动已连接的零件时由约束求解器带动其余零件，松手后零速度松弛，铰链等连接不会分离
- 「设为初始状态」把当前布局存为初始状态，之后「重置」回到这里；暂停时也可把当前运行姿态冻结为新的初始状态（速度清零）。编辑模式下初始状态随布局自动更新
- 实时速度/力箭头、轨迹、能量读数与曲线
- 17 个预设：单摆、曲柄滑块、四连杆、弹簧-质量、投石机、斜面滚轮与滑块、两级齿轮减速器、皮带传动、链传动、凸轮-从动件、偏心凸轮、齿轮齿条、丝杠螺母、蜗杆蜗轮、槽轮机构、离合器+飞轮、棘轮棘爪
- 保存/读取 JSON，导出 BOM（CSV）与 PNG
- 撤销 / 重做

## 使用

用浏览器直接打开 `index.html`，无需构建。

- `Space`：运行 / 暂停
- `Delete`：删除
- `R`：旋转
- `Ctrl+Z` / `Ctrl+Y`：撤销 / 重做

## 局限

- 仅二维
- 电机固定在地面
- 极端质量比钳制到 1:1000，以保证稳定
- 无连续碰撞检测，过快的细长物体可能穿透
- 仅在 Chrome 中测试过
- 传动在速度级简化，没有齿面接触，也没有齿侧间隙
- 锥齿轮、蜗杆蜗轮按传动比元件处理
- 槽轮为运动学模型
- 差速器未实现
